📄 Що таке HTML. Структура Web-сторінки

🌐 HTML (HyperText Markup Language) — це мова розмітки, яка використовується для створення веб-сторінок. Вона визначає структуру та вміст сторінки: заголовки, абзаци, зображення, посилання тощо.

Що таке HTML?

HTML — це не мова програмування, а мова розмітки. Вона складається з тегів, які "говорять" браузеру, як відображати контент. Браузер читає HTML-код і показує користувачеві гарно оформлену сторінку.

<h1>Це заголовок</h1>
<p>Це абзац тексту.</p>
<a href="https://example.com">Це посилання</a>

📌 Кожен тег має відкриваючу <тег> та закриваючу </тег> частини. Вміст між ними — це те, що побачить користувач.

Структура HTML-документа

<!DOCTYPE html> — оголошення типу документа (повідомляє браузеру, що це HTML5)
<html> — кореневий елемент, у якому міститься вся сторінка
<head> — метадані сторінки (не відображаються на сторінці)
<title>Назва вкладки</title> — заголовок вкладки браузера
<meta charset="UTF-8"> — кодування символів
<link rel="stylesheet" href="style.css"> — підключення CSS
</head>
<body> — тіло сторінки (все, що бачить користувач)
<h1>Заголовок</h1>
<p>Абзац тексту...</p>
<img src="photo.jpg" alt="Опис">
</body>
</html>

Основні теги HTML

<h1> - <h6>

Заголовки

Найважливіший заголовок — h1, далі за спаданням — h2, h3... Використовуються для структурування контенту.

<p>

Абзац

Для звичайного тексту. Браузер автоматично додає відступи між абзацами.

<a>

Посилання

Атрибут href вказує адресу переходу. <a href="https://google.com">Google</a>

<img>

Зображення

Атрибути: src (шлях до файлу) та alt (альтернативний текст).

<ul>, <ol>, <li>

Списки

Маркований (ul) та нумерований (ol) списки. Елементи списку — li.

<div>

Контейнер

Універсальний блок для групування елементів. Часто використовується з CSS.

✅ Правильно

  • Закривати всі теги, які мають закриваючу пару
  • Використовувати правильну вкладеність тегів
  • Додавати alt до зображень
  • Дотримуватись структури html → head → body

❌ Неправильно

  • Забувати закривати теги (наприклад, <p>текст)
  • Перехресна вкладеність (<b><i>текст</b></i>)
  • Використовувати теги для форматування (краще CSS)

📝 Приклад повної HTML-сторінки

<!DOCTYPE html>
<html lang="uk">
  <head>
    <meta charset="UTF-8">
    <title>Моя перша сторінка</title>
  </head>
  <body>
    <h1>Вітаю на моєму сайті!</h1>
    <p>Це мій перший досвід роботи з HTML.</p>
    <ul>
      <li>Вивчаю HTML</li>
      <li>Пізнаю CSS</li>
      <li>Готуюсь до JavaScript</li>
    </ul>
    <a href="https://www.w3schools.com/html/" target="_blank">Більше про HTML</a>
  </body>
</html>
