🌐 А що ж таке WEB-сайт?

Вебсайт — це сукупність вебсторінок, об'єднаних темою, які доступні через Інтернет. Сайти складаються з коду (HTML — структура, CSS — стилі, JavaScript — поведінка). Коли ти відкриваєш сторінку, браузер завантажує файли з сервера і показує тобі гарну картинку!

Як це працює: Твій пристрій ➡️ Запит через Інтернет ➡️ Сервер віддає файли ➡️ Браузер малює сайт.

Правила безпеки роботи за комп'ютером

  • Не повідомляй нікому свої паролі.
  • Використовуй надійні паролі (букви + цифри + символи).
  • Не відкривай підозрілі посилання та листи.
  • Роби перерви кожні 20 хвилин — гімнастика для очей!
  • Сиди рівно, відстань до монітора — 50-70 см.
