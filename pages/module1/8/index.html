Тег <img> та його атрибути

Тег <img> (від англ. image — зображення) використовується для вставки зображень на веб-сторінку. Це непарний тег, тому він не потребує закриття.

src
Обов'язковий атрибут! Вказує шлях до файлу зображення
alt
Альтернативний текст (показується, якщо зображення не завантажилось)
width / height
Ширина та висота зображення (в пікселях або відсотках)
title
Підказка при наведенні миші
loading="lazy"
Відкладене завантаження (оптимізація швидкості)
<img src="images/photo.jpg" alt="Опис зображення" width="300" height="200" title="Підказка">

Популярні формати зображень

📷 JPEG / JPG

Найпопулярніший формат для фотографій. Добре стискається, але не підтримує прозорість.

🌄 Фотографії, пейзажі, портрети

🔲 PNG

Підтримує прозорість. Використовується для логотипів, іконок, графіки.

✨ Логотипи, іконки, графіка з прозорістю

🎨 GIF

Підтримує анімацію. Обмежена кількість кольорів (256).

🎬 Анімація, прості гіфки

⚡ WebP

Сучасний формат від Google. Краще стиснення, ніж JPEG та PNG.

🚀 Швидке завантаження сайтів

📂 Шляхи до зображень: як правильно вказати шлях до файлу

Щоб браузер знайшов зображення, потрібно правильно вказати шлях у атрибуті src. Шляхи бувають абсолютні та відносні.

🌐 Абсолютні шляхи (URL)

Вказують повну адресу зображення в інтернеті. Починаються з http:// або https://.

<img src="https://example.com/images/photo.jpg" alt="Фото з інтернету">

✔️ Працює з будь-якого місця
❌ Потребує інтернету
❌ Якщо сайт видалить фото — воно зникне

📁 Відносні шляхи

Вказують шлях відносно поточної HTML-сторінки. Найкращий варіант для локальних файлів!

<img src="photo.jpg" alt="Фото поруч">

✔️ Працює без інтернету
✔️ Не залежить від зовнішніх сайтів
✔️ Легко переносити проект

Як правильно писати відносні шляхи у VS Code?

📄 Файл index.html і зображення cat.jpg в одній папці
<img src="cat.jpg">
Просто назва файлу
📁 Зображення в папці images/ (поруч з index.html)
<img src="images/cat.jpg">
Назва папки + / + назва файлу
📂 Зображення в папці images/gallery/ (вкладена папка)
<img src="images/gallery/cat.jpg">
Вкладені папки через /
⬆️ Зображення на рівень вище (в батьківській папці)
<img src="../cat.jpg">
../ — піднятися на один рівень вгору
⬆️⬆️ Зображення на два рівні вище
<img src="../../cat.jpg">
../../ — піднятися на два рівні вгору
🏠 Кореневий шлях (починається з /)
<img src="/images/cat.jpg">
Шукає від кореня сайту (не завжди працює локально)
📁 Приклад структури папок:
my_site/
├── index.html (головна сторінка)
├── about.html
├── images/
│ ├── cat.jpg → src="images/cat.jpg"
│ ├── dog.png
│ └── gallery/
│ └── photo.jpg → src="images/gallery/photo.jpg"
└── css/
└── style.css

💡 Порада: У VS Code при наборі src=" з'являється підказка — обирай файл зі списку, щоб не помилитися!

📋 Вікторина: Перевір себе

Що потрібно запам'ятати

  • Тег <img> — непарний, не потребує закриття
  • Атрибут src — обов'язковий (шлях до зображення)
  • Атрибут alt — опис зображення (для доступності та SEO)
  • JPEG — для фото, PNG — для прозорості, GIF — для анімації
  • Атрибут loading="lazy" пришвидшує завантаження сторінки

Покрокова інструкція

1
Створи базову структуру HTML-документа.
2
Додай зображення за допомогою тега <img>.
3
Додай атрибути src, alt, width, height.
4
Покращ сторінку "Моє хобі", додавши зображення до кожного пункту.
🎯 Завдання-челендж

Створи сторінку "Моє хобі" зі зображеннями, яка має містити:

  • Заголовок <h1> з назвою хобі
  • Головне зображення (шириною 300-400px)
  • Абзац з описом хобі
  • Список з 3+ елементів, кожен з яких має маленьке зображення (іконку)
  • Атрибут alt для кожного зображення
