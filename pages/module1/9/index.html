📊 Таблиці в HTML

📜 Історія: Таблиці та верстка сайтів

У 90-х роках, коли CSS ще не існувало, таблиці використовували для верстки цілих сайтів! Дизайнери вкладали таблиці одну в одну, щоб створити складні макети. Це називалося "табличною версткою". Сьогодні це вважається застарілим методом, але знати його корисно для розуміння історії веб-розробки.

🏗️ Теги для створення таблиць

<table>
Контейнер для всієї таблиці
<tr> (table row)
Рядок таблиці
<td> (table data)
Комірка з даними
<th> (table header)
Заголовкова комірка (жирний шрифт, центрування)
<thead>
Групує заголовки таблиці
<tbody>
Групує основний вміст таблиці
<tfoot>
Групує підсумки таблиці
<caption>
Заголовок таблиці (підпис)
<table border="1">
  <tr>
    <th>Ім'я</th>
    <th>Вік</th>
  </tr>
  <tr>
    <td>Марія</td>
    <td>15</td>
  </tr>
</table>

🔗 Об'єднання комірок

📏 colspan — об'єднання по горизонталі

<td colspan="2">Текст</td>

Розтягує комірку на 2 стовпці

📐 rowspan — об'єднання по вертикалі

<td rowspan="3">Текст</td>

Розтягує комірку на 3 рядки

🎨 Атрибути таблиць (історія та сучасність)

Увага! Раніше для оформлення таблиць використовували атрибути: border, bgcolor, cellpadding, cellspacing, width, height, align, valign. Сьогодні все це робиться за допомогою CSS!

❌ Застарілі атрибути (не використовувати!)

<table border="1" cellpadding="10" cellspacing="5" bgcolor="#e8f4fd" width="500">
  <tr align="center" valign="middle">
    <td height="50">Текст</td>
  </tr>
</table>

✅ Сучасний підхід (CSS)

<style>
  table { border-collapse: collapse; width: 500px; }
  td { border: 1px solid #000; padding: 10px; }
  tr { background: #e8f4fd; text-align: center; }
</style>

У практичній частині ми будемо використовувати CSS для стилізації таблиць — це сучасний і правильний підхід!

📋 Вікторина: Перевір себе

Що потрібно запам'ятати

  • Таблиці створюються тегами: <table>, <tr>, <td>, <th>
  • colspan — об'єднання комірок по горизонталі
  • rowspan — об'єднання комірок по вертикалі
  • Для стилізації таблиць використовуємо CSS, а не застарілі атрибути
  • Таблиці використовуються ТІЛЬКИ для табличних даних, не для верстки сайтів!

💻 Практикуємося з таблицями

💪 Практичне завдання: створи кольорову таблицю з об'єднанням комірок та CSS-стилізацією.

Мета практичного заняття

  • Створити HTML-таблицю з розкладом уроків
  • Використати об'єднання комірок (colspan, rowspan)
  • Застосувати CSS для стилізації: кольори, рамки, відступи, центрування
  • Додати заголовок таблиці (caption)

Покрокова інструкція

1
Створи базову структуру HTML-документа.
2
Додай тег <table> та створи заголовки стовпців через <th>.
3
Заповни таблицю даними (розклад уроків на тиждень).
4
Додай об'єднання комірок (наприклад, велику зміну або класну годину).
5
Застосуй CSS-стилі для таблиці: кольори фону, рамки, вирівнювання.
🎯 Завдання-челендж

Створи сторінку "Мій розклад уроків", яка має містити:

  • Таблицю 5x5 (5 днів, 5 уроків)
  • Заголовки днів тижня <th>
  • Об'єднання комірок (colspan або rowspan)
  • CSS-стилі: рамки, фон, відступи, центрування тексту
  • Заголовок таблиці <caption>
  • Різні кольори для різних типів уроків
