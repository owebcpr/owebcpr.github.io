📝 Перший HTML-файл. Частина 1

💪 Практичне завдання: сьогодні ми створимо нашу першу веб-сторінку! Ти навчишся писати HTML-код і одразу бачити результат у браузері.

Мета заняття

  • Створити перший HTML-файл з нуля
  • Навчитися використовувати базові теги: <h1>, <p>, <ul>, <li>
  • Зрозуміти структуру HTML-документа

Як створити HTML-проєкт у Visual Studio Code

  1. 📁 Відкрий Visual Studio Code
  2. 📂 Натисни File → Open Folder і обери папку для проєкту
  3. ➕ У лівій панелі (Explorer) натисни праву кнопку миші → New File
  4. 📄 Назви файл index.html
  5. ✏️ Пиши код у файлі
  6. 🌐 Збережи файл (Ctrl+S) і відкрий його у браузері (подвійний клік)

Подивись відео-інструкцію, щоб краще зрозуміти процес

Покрокова інструкція

1
Створи файл з іменем index.html на комп'ютері (або пиши код прямо в редакторі нижче).
2
Додай базову структуру HTML-документа: <!DOCTYPE html>, <html>, <head>, <body>.
3
У <head> додай заголовок сторінки: <title>Мій перший сайт</title> та кодування: <meta charset="UTF-8">.
4
У <body> додай заголовок, абзац і список.
Підказка: Ось базова структура:
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
    <title>Мій перший сайт</title>
  </head>
  <body>
    <h1>...</h1>
    <p>...</p>
    <ul><li>...</li></ul>
  </body>
</html>

Приклад готової сторінки: 
<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <title>Мій перший сайт</title>
</head>
<body>
    <h1>Ласкаво просимо на мій перший сайт!</h1>
    <p>Мене звати Олександр, і це моя перша веб-сторінка.</p>
    <h2>Мої захоплення:</h2>
    <ul>
        <li>Програмування</li>
        <li>Спорт</li>
        <li>Музика</li>
    </ul>
</body>
</html>

📋 Контрольні питання

Що потрібно запам'ятати

  • Кожен HTML-документ починається з <!DOCTYPE html>
  • Весь контент сторінки знаходиться всередині тегу <body>
  • Мета-тег <meta charset="UTF-8"> потрібен для українських літер
