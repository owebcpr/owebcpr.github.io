📝 Створення форм у HTML

🎯 Мета заняття: Повторити основні теги для створення форм, різні типи полів, атрибути та потренуватися в редакторі коду.

Згадаймо: теги для створення форм

<form>
Контейнер для всієї форми
<input>
Поле введення (текст, пароль, email, число, прапорець, перемикач)
<label>
Підпис для поля (покращує доступність)
<select> + <option>
Випадаючий список
<textarea>
Багаторядкове текстове поле
<button>
Кнопка

Важливі атрибути

📌 Атрибути <form>

action="/send-data" — куди відправляти
method="POST" — метод відправки
name="registration" — ім'я форми

📌 Атрибути <input>

type="text" — тип поля
name="username" — ім'я поля
placeholder="Введіть ім'я" — підказка
required — обов'язкове поле

Приклад простої форми

<form action="/register" method="POST">
  <label>Ім'я:</label>
  <input type="text" name="name" placeholder="Ваше ім'я" required>

  <label>Email:</label>
  <input type="email" name="email" placeholder="email@example.com">

  <input type="submit" value="Надіслати">
</form>

Завдання 1: Створи форму входу

Створи форму для входу на сайт. Форма повинна мати:

  • Поле для логіну (type="text") з підказкою "Введіть логін"
  • Поле для пароля (type="password") з підказкою "Введіть пароль"
  • Кнопку відправки (type="submit") з текстом "Увійти"
  • Тег <form> з атрибутами action="/login" та method="POST"
  • Атрибут required для обох полів обов'язкове заполнення
Підказка: використай <form>, <input>, <placeholder>, <value>

Як створити HTML-проєкт у Visual Studio Code

  1. 📁 Відкрий Visual Studio Code
  2. 📂 Натисни File → Open Folder і обери папку для проєкту
  3. ➕ У лівій панелі (Explorer) натисни праву кнопку миші → New File
  4. 📄 Назви файл index.html
  5. ✏️ Пиши код у файлі
  6. 🌐 Збережи файл (Ctrl+S) і відкрий його у браузері
