📚 Основні теги HTML

🎯 Мета заняття: Вивчити основні HTML-теги, їх призначення, навчитися розрізняти парні та непарні теги, ознайомитися із сучасними та застарілими тегами.

Сьогодні ми розглянемо

  • Що таке HTML-теги та як вони працюють
  • Парні та непарні теги
  • Основні теги для тексту: <h1>, <p>, <strong>, <em>
  • Теги для списків: <ul>, <ol>, <li>
  • Застарілі та сучасні теги HTML5

Що таке HTML-теги?

Теги — це спеціальні команди, які говорять браузеру, як відображати контент. Вони пишуться в кутових дужках: <тег>.

Більшість тегів мають відкриваючу та закриваючу частини: <p>Текст</p>. Такі теги називаються парними.

Парні та непарні теги

📖 Парні теги (контейнери)

Мають відкриваючий та закриваючий тег. Впливають на текст між ними.

<h1>Заголовок</h1>
<p>Абзац тексту</p>
<strong>Жирний текст</strong>
<em>Курсив</em>

⚡ Непарні теги (самозакривні)

Не мають закриваючого тега. Використовуються для вставки об'єктів.

<br> — перенос рядка
<hr> — горизонтальна лінія
<img src="photo.jpg"> — зображення
<input type="text"> — поле вводу

Атрибути тегів: додаткові властивості

Атрибути — це додаткові параметри, які уточнюють або змінюють поведінку тега. Вони пишуться всередині відкриваючого тега.

Синтаксис: <тег атрибут="значення"> вміст </тег>

<a href="https://google.com" target="_blank">Посилання</a>
<img src="photo.jpg" alt="Моє фото" width="200">

📌 Загальні атрибути (для всіх тегів)

id — унікальний ідентифікатор
class — клас для групування елементів
style — вбудовані CSS-стилі
title — підказка при наведенні
hidden — приховує елемент
<p id="first" class="text" title="Це підказка">Текст</p>

⚡ Індивідуальні атрибути (для конкретних тегів)

href — для <a> (адреса посилання)
src — для <img> (шлях до зображення)
alt — для <img> (альтернативний текст)
type — для <input> (тип поля)
value — для <input> (значення)
<img src="cat.jpg" alt="Пухнастий кіт">
<input type="text" value="Привіт">

Важливо! Атрибути завжди пишуться у відкриваючому тезі. Значення атрибутів беруться в лапки (подвійні або одинарні). Наприклад: class="my-class" або class='my-class'.

Таблиця популярних атрибутів

id="унікальне_ім'я"
Унікальний ідентифікатор (тільки один на сторінці)
class="ім'я_класу"
Клас для групування (можна багато однакових)
style="property: value"
Вбудовані CSS-стилі (зміна кольору, розміру тощо)
title="текст"
Спливаюча підказка при наведенні
href="url"
Адреса переходу (для тега <a>)
src="шлях"
Шлях до файлу (для <img>, <script>, <iframe>)
alt="текст"
Альтернативний текст (якщо картинка не завантажилась)
width="число" / height="число"
Ширина та висота елемента (в пікселях)
required
Обов'язкове поле форми (не потребує значення)
disabled
Вимкнений елемент (не потребує значення)

Цікавий факт: Деякі атрибути не потребують значення! Наприклад, required, disabled, hidden, checked. Їх достатньо просто написати всередині тега.

Основні теги для роботи з текстом

<h1>...</h1> — <h6>
Заголовки різних рівнів (від найважливішого до найменш важливого)
<p>...</p>
Абзац тексту
<strong>...</strong>
Жирне виділення (важливий текст)
<em>...</em>
Курсивне виділення (логічний наголос)
<b>...</b>
Жирний текст (без логічного значення)
<i>...</i>
Курсивний текст (без логічного значення)
<br>
Перехід на новий рядок (непарний)
<hr>
Горизонтальна лінія (непарний)

Теги для створення списків

📌 Маркований список (ul)

<ul>
  <li>Елемент 1</li>
  <li>Елемент 2</li>
</ul>

🔢 Нумерований список (ol)

<ol>
  <li>Перший</li>
  <li>Другий</li>
</ol>

Застарілі теги (не використовувати!)

Ці теги більше не підтримуються в HTML5. Використовуй CSS замість них!

❌ Застарілі

<font> — для шрифтів (використовуй CSS)
<center> — для центрування (CSS: text-align)
<big> — великий текст (CSS: font-size)
<strike> — закреслений текст (CSS: text-decoration)
<u> — підкреслення (CSS: text-decoration)

✅ Сучасні теги HTML5

<header> — шапка сайту
<nav> — навігація
<main> — головний контент
<section> — розділ
<article> — стаття
<footer> — підвал
<aside> — бічна панель

📋 Вікторина: Перевір себе

Що потрібно запам'ятати

  • HTML-теги — це команди для браузера, які пишуться в кутових дужках < >
  • Парні теги мають відкриваючу і закриваючу частину (наприклад, <p></p>)
  • Непарні теги не потребують закриття (наприклад, <br>, <hr>)
  • Застарілі теги (<font>, <center>) замінюються CSS

💻 Практикуємося з тегами HTML

💪 Практичне завдання: закріпимо знання про HTML-теги на практиці! Ти напишеш свій перший HTML-код і одразу побачиш результат.

Мета практичного заняття

  • Написати HTML-код з використанням вивчених тегів
  • Створити сторінку "Моя улюблена книга"
  • Потренуватися з заголовками, абзацами, списками

Покрокова інструкція

1
Створи файл з іменем index.html (або пиши код прямо в редакторі нижче).
2
Додай базову структуру HTML-документа: <!DOCTYPE html>, <html>, <head>, <body>.
3
У <head> додай заголовок сторінки: <title>Моя улюблена книга</title> та кодування: <meta charset="UTF-8">.
4
У <body> додай:
  • Заголовок <h1> з назвою книги
  • Абзац <p> з описом
  • Заголовок <h2> "Цікаві факти"
  • Маркований список <ul> з 3 фактами
  • Виділення важливих слів за допомогою <strong> або <em>
Підказка: Ось базова структура, яка має вийти:
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
    <title>Моя улюблена книга</title>
  </head>
  <body>
    <h1>...</h1>
    <p>...</p>
    <h2>Цікаві факти</h2>
    <ul><li>...</li></ul>
  </body>
</html>
🎯 Завдання-челендж

Створи сторінку "Моя улюблена книга", яка має містити:

  • Заголовок <h1> з назвою книги
  • Абзац <p> з описом книги
  • Заголовок <h2> "Цікаві факти"
  • Маркований список <ul> з 3 цікавими фактами
  • Виділення слів за допомогою <strong> або <em>
  • Горизонтальну лінію <hr> між розділами (за бажанням)

📋 Контрольні питання

Що потрібно запам'ятати

  • Кожен HTML-документ починається з <!DOCTYPE html>
  • Весь контент сторінки знаходиться всередині тегу <body>
  • Мета-тег <meta charset="UTF-8"> потрібен для українських літер
  • Використовуй <strong> для важливого тексту, <em> для наголосу
