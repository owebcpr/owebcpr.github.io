📊 Створення таблиць у HTML

🎯 Мета заняття: Повторити основні теги для створення таблиць, потренуватися в редакторі коду та створити власну сторінку з таблицею.

Згадаймо: теги для створення таблиць

<table>
Контейнер для всієї таблиці
<tr>
Table Row - рядок таблиці
<td>
Table Data - звичайна комірка
<th>
Table Header - заголовна комірка (жирний шрифт)
<caption>
Заголовок таблиці
<thead>, <tbody>, <tfoot>
Групування рядків (голова, тіло, підвал)

Приклад простої таблиці

<table border="1">
  <caption>Мій розклад</caption>
  <tr>
    <th>День</th>
    <th>Справи</th>
  </tr>
  <tr>
    <td>Понеділок</td>
    <td>Програмування</td>
  </tr>
</table>

Завдання 1: Створи таблицю з продуктами

Створи таблицю з продуктами, які потрібно купити. Таблиця повинна мати:

  • Заголовок таблиці: "Список покупок" (тег <caption>)
  • Заголовки колонок: №, Назва, Кількість
  • 3 рядки з товарами (наприклад: молоко, хліб, яблука)
  • Границі таблиці: border="1"
Підказка: використай теги: <table>, <caption>, <tr>, <th>, <td>

📁 Створюємо повноцінний HTML-проєкт

Як створити HTML-проєкт у Visual Studio Code

  1. 📁 Відкрий Visual Studio Code
  2. 📂 Натисни File → Open Folder і обери папку для проєкту
  3. ➕ У лівій панелі (Explorer) натисни праву кнопку миші → New File
  4. 📄 Назви файл index.html
  5. ✏️ Пиши код у файлі
  6. 🌐 Збережи файл (Ctrl+S) і відкрий його у браузері

Фінальне завдання: "Розклад уроків"

Тепер, коли ти навчився створювати таблиці, створи власну сторінку з таблицею "Мій розклад уроків" у VS Code.

1
Створи файл index.html у VS Code.
2
Додай базову структуру HTML-документа:
<!DOCTYPE html>
<html lang="uk">
  <head>
    <meta charset="UTF-8">
    <title>Мій розклад уроків</title>
  </head>
  <body>
    <!-- Тут буде таблиця -->
  </body>
</html>
3
Додай заголовок сторінки за допомогою тегу <h1> з текстом "Мій розклад уроків".
4
Створи таблицю з наступною структурою:
  • Заголовки колонок: "День тижня", "Понеділок", "Вівторок", "Середа", "Четвер", "П'ятниця"
  • Рядки: "1 урок", "2 урок", "3 урок", "4 урок", "5 урок"
  • Заповни комірки назвами предметів (вигадай самостійно)
5
Додай стилі для таблиці (ми ще не вивчали CSS, але скопіюй цей код у секцію <head>):

🎨 Стилі для таблиці

Скопіюй цей код у секцію <head> (після тегу <title>):

<style>
  table {
    border-collapse: collapse;
    width: 100%;
    margin: 20px 0;
    font-family: Arial, sans-serif;
  }
  th, td {
    border: 1px solid #ddd;
    padding: 12px;
    text-align: center;
  }
  th {
    background-color: #1e5f7a;
    color: white;
  }
  tr:nth-child(even) {
    background-color: #f2f2f2;
  }
  tr:hover {
    background-color: #ffd966;
  }
  h1 {
    color: #1e5f7a;
    text-align: center;
  }
</style>

Не хвилюйся, ми ще не вивчали CSS! Просто скопіюй ці стилі — вони зроблять твою таблицю красивою, з кольоровими заголовками, чергуванням рядків та підсвіткою при наведенні.

6
Збережи файл (Ctrl+S) та відкрий у браузері (двічі клікни на файлі).
