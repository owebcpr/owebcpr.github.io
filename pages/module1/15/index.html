Що таке проєктування сайту?

Проєктування — це перший і найважливіший етап створення сайту. На цьому етапі ми:

  • 📌 Визначаємо мету та цільову аудиторію
  • 🗺️ Створюємо карту сайту (sitemap)
  • 📐 Малюємо макет (вайрфрейм)
  • 🎨 Продумуємо навігацію та структуру сторінок
  • 📁 Організовуємо файли проєкту

STEAM-підхід: Поєднує науку, технології, інженерію, мистецтво та математику для створення якісного продукту!

💻 Створюємо власний сайт у VS Code

💪 Практичне завдання: Спроєктувати та створити багатосторінковий сайт про своє хобі або улюблену тему.

🚀 Основний проєкт: Сайт про моє хобі

Тобі потрібно створити сайт з 3-4 сторінок на тему твого хобі (спорт, музика, програмування, малювання, подорожі тощо).

📋 Вимоги до проєкту:

  • Мінімум 3 сторінки (головна, про хобі, галерея, контакти)
  • Семантична структура (header, nav, main, footer)
  • Навігаційне меню на всіх сторінках
  • Зображення (хоча б 2-3)
  • Стилі в окремому файлі CSS
  • Адаптивність (медіа-запити для мобільних)

📝 Покрокове керівництво

1 Планування та структура папок

Створи папку проєкту та потрібні файли.

Створи таку структуру:

my_hobby_site/
├── index.html
├── about.html
├── gallery.html
├── contact.html
├── css/
│   └── style.css
├── images/
│   ├── photo1.jpg
│   └── photo2.jpg
└── js/
    └── script.js
2 Створення HTML-скелета

Створи базову структуру HTML для головної сторінки.

Базова структура HTML5:

<!DOCTYPE html>
<html lang="uk">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Моє хобі</title>
    <link rel="stylesheet" href="css/style.css">
</head>
<body>
    <header>...</header>
    <nav>...</nav>
    <main>...</main>
    <footer>...</footer>
    <script src="js/script.js"></script>
</body>
</html>
3 Навігаційне меню

Створи навігацію, яка буде однаковою на всіх сторінках.

Приклад навігаційного меню:

<nav>
    <ul>
        <li><a href="index.html">Головна</a></li>
        <li><a href="about.html">Про хобі</a></li>
        <li><a href="gallery.html">Галерея</a></li>
        <li><a href="contact.html">Контакти</a></li>
    </ul>
</nav>
4 Стилізація з CSS

Додай кольори, шрифти, відступи та зроби сайт красивим.

Приклад базових стилів:

/* Загальні стилі */
* {
    margin: 0;
    padding: 0;
    box-sizing: border-box;
}

body {
    font-family: 'Segoe UI', sans-serif;
    line-height: 1.6;
    color: #333;
}

header {
    background: #2c3e50;
    color: white;
    padding: 20px;
    text-align: center;
}

nav {
    background: #34495e;
    padding: 10px;
}

nav ul {
    list-style: none;
    display: flex;
    justify-content: center;
    gap: 20px;
}

nav a {
    color: white;
    text-decoration: none;
}
5 Адаптивність

Додай медіа-запити для коректного відображення на телефонах.

Приклад медіа-запиту:

/* Для мобільних пристроїв */
@media (max-width: 768px) {
    nav ul {
        flex-direction: column;
        align-items: center;
    }
    
    main {
        padding: 10px;
    }
}
6 Перевірка та тестування

Перевір, чи всі посилання працюють, чи правильно відображаються зображення.

Що перевірити:

  • ✅ Всі посилання ведуть на правильні сторінки
  • ✅ Зображення завантажуються (перевір шляхи)
  • ✅ Сайт гарно виглядає на різних розмірах екрану
  • ✅ Немає не закритих тегів
