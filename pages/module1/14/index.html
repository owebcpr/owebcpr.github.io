🏗️ Семантичні теги HTML5

🎯 Мета заняття: Вивчити семантичні теги HTML5, зрозуміти їх важливість для SEO та доступності, навчитися правильно структурувати веб-сторінки.

📦 Строкові та блокові елементи. Семантичні теги

Блокові елементи (block-level):

  • Завжди починаються з нового рядка
  • Займають всю доступну ширину
  • Можуть містити інші блокові та строкові елементи
  • Приклади: <div>, <p>, <h1>-<h6>, <ul>, <li>, <header>, <footer>, <main>, <section>, <article>, <aside>, <nav>

Строкові елементи (inline):

  • Не починають новий рядок
  • Займають лише необхідну ширину
  • Не можуть містити блокові елементи
  • Приклади: <span>, <a>, <strong>, <em>, <img>, <mark>, <time>

🔍 Головна відмінність:

Блокові елементи створюють структуру сторінки, а строкові — форматують текст всередині блоків.

🏷️ Семантичні теги — це блокові елементи, які називають себе за призначенням: header, nav, main, article, section, aside, footer.

Відео: Строкові та блокові елементи. Що таке семантичні теги та як їх використовувати

Що таке семантичні теги?

Семантичні теги — це теги, які несуть смислове навантаження, описують призначення контенту. На відміну від універсальних <div> та <span>, семантичні теги пояснюють браузеру та пошуковим системам, що саме знаходиться всередині.

Цікавий факт: Семантичні теги з'явилися в HTML5 у 2014 році. До цього розробники використовували <div> з класами, наприклад, "header" або "footer"!

Основні семантичні теги

<header>
Верхня частина сторінки або секції (логотип, навігація, заголовок)
<nav>
Блок навігації, меню сторінки
<main>
Основний унікальний контент сторінки
<article>
Самостійний контент (стаття, пост, новина)
<section>
Логічна група контенту (розділ сторінки)
<aside>
Бічний контент (сайдбар, додаткова інформація)
<footer>
Нижня частина сторінки або секції
<figure> / <figcaption>
Ілюстрації з підписами
<mark>
Виділений текст (строковий)
<time>
Дата та час (строковий)

Типова структура семантичної сторінки

<body>
  <header>...</header>
  <nav>...</nav>
  <main>
    <article>...</article>
    <aside>...</aside>
  </main>
  <footer>...</footer>
</body>

SEO та пошукові системи

Як пошукові системи читають сторінки? Роботи Google, Bing та інших пошукачів сканують HTML-код сторінки. Семантичні теги допомагають роботам зрозуміти структуру: де заголовок, де навігація, де основний контент. Це покращує індексацію та позиції сайту в пошуку!

📈 Переваги семантики для SEO

  • Краща індексація сторінок
  • Вищі позиції в пошуку
  • Покращення CTR (клікабельності)
  • Роботи краще розуміють контент

♿ Доступність (Accessibility)

  • Screen readers (екранні диктори)
  • Навігація з клавіатури
  • Користувачі з обмеженими можливостями
  • Відповідність WCAG стандартам

Зверни увагу! Використання семантичних тегів — це не тільки про SEO, але й про гарний тон розробника. Код стає зрозумілішим для інших програмістів!

📝 Завдання: заміни div на семантичні теги

У коді нижче використовуються звичайні <div> з класами. Заміни їх на правильні семантичні теги:

class="header" → <header> class="nav" → <nav> class="main" → <main> class="article" → <article> class="section" → <section> class="aside" → <aside> class="footer" → <footer>
Початковий код (з div) 
<div class="header">
                    <h1>Мій сайт</h1>
                </div>

                <div class="nav">
                    <a href="#">Головна</a>
                    <a href="#">Про нас</a>
                    <a href="#">Контакти</a>
                </div>

                <div class="main">
                    <div class="article">
                        <h2>Стаття 1</h2>
                        <p>Це цікава стаття про семантичні теги.</p>
                    </div>
                    
                    <div class="section">
                        <h3>Розділ</h3>
                        <p>Додаткова інформація.</p>
                    </div>
                </div>

                <div class="aside">
                    <h4>Бічна панель</h4>
                    <p>Реклама або посилання.</p>
                </div>

                <div class="footer">
                    <p>© 2026 Мій сайт</p>
                </div>

Підказки

  • <header> — для верхньої частини (шапки) замість class="header"
  • <nav> — для навігаційного меню замість class="nav"
  • <main> — для основного контенту замість class="main"
  • <article> — для окремої статті/посту замість class="article"
  • <section> — для групування контенту замість class="section"
  • <aside> — для бічної інформації (сайдбар) замість class="aside"
  • <footer> — для нижньої частини (підвалу) замість class="footer"
  • Не забудь закрити всі теги! Наприклад: <header>...</header>
