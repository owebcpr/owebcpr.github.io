📋 Списки на Web-сторінці

🎯 Мета заняття: Вивчити всі види списків у HTML, навчитися створювати марковані, нумеровані та списки визначень, використовувати вкладені списки.

Історія виникнення списків у HTML

Списки з'явилися в HTML ще в першій специфікації 1993 року! Тім Бернерс-Лі розумів, що структурована інформація надзвичайно важлива для веб-документів. Саме списки допомагають організувати інформацію логічно та зручно для сприйняття.

Цікавий факт: Сучасні вебсайти використовують списки не тільки для тексту, але й для створення меню, навігації, карток товарів, галерей зображень та багато іншого!

Види списків у HTML

📌 Маркований список (<ul>)

Використовується для непослідовних пунктів. Маркери можуть бути різних типів.

<ul>
  <li>Елемент 1</li>
  <li>Елемент 2</li>
</ul>
  • Яблуко
  • Груша
  • Банан

🔢 Нумерований список (<ol>)

Використовується для послідовних пунктів. Нумерація може бути різних типів.

<ol>
  <li>Перший</li>
  <li>Другий</li>
</ol>
  1. Перший крок
  2. Другий крок
  3. Третій крок

Список визначень (<dl>, <dt>, <dd>)

📖 Як виглядає список визначень

<dl>
  <dt>HTML</dt>
  <dd>Мова розмітки веб-сторінок</dd>
  <dt>CSS</dt>
  <dd>Мова стилів для оформлення</dd>
</dl>

✨ Результат

HTML
Мова розмітки веб-сторінок
CSS
Мова стилів для оформлення

Типи маркерів та нумерації

list-style-type: disc
● Заповнений кружечок (тип за замовчуванням для ul)
list-style-type: circle
○ Порожній кружечок
list-style-type: square
■ Квадратик
type="1" (ol)
1, 2, 3, ... (цифри)
type="A" (ol)
A, B, C, ... (великі літери)
type="a" (ol)
a, b, c, ... (малі літери)
type="I" (ol)
I, II, III, ... (римські великі)

Що потрібно запам'ятати

  • <ul> — маркований список (unordered list)
  • <ol> — нумерований список (ordered list)
  • <li> — елемент списку (list item)
  • <dl>, <dt>, <dd> — список визначень
  • Списки можна вкладати один в одного
  • Змінювати маркери можна за допомогою CSS властивості list-style-type

💻 Практикуємося зі списками

💪 Практичне завдання: створи сторінку з різними видами списків, навчися вкладати списки та змінювати типи маркерів.

Мета практичного заняття

  • Створити маркований список з продуктами
  • Створити нумерований список з рецептом
  • Створити вкладений список (меню ресторану)
  • Створити список визначень (словник термінів)

Покрокова інструкція

1
Створи базову структуру HTML-документа.
2
Додай маркований список продуктів для покупки.
3
Додай нумерований список з рецептом приготування улюбленої страви.
4
Створи вкладений список (меню ресторану з категоріями та стравами).
5
Створи список визначень (словник нових термінів).
🎯 Завдання-челендж

Створи сторінку "Мій ідеальний день", яка має містити:

  • Маркований список <ul> з планами на день
  • Нумерований список <ol> з розкладом по годинах
  • Вкладений список (справи з підпунктами)
  • Список визначень <dl> з новими словами
  • Змінений тип маркера для одного зі списків
