🎥 Відео-урок: Форми в HTML

Подивись відео, щоб дізнатися, як створювати форми для збору інформації від користувачів!

Що таке форми?

Форми — це елементи вебсторінки, які дозволяють користувачам вводити та відправляти дані: реєстрація, вхід, пошук, опитування, замовлення тощо.

Форми — це "місток" між користувачем і сервером. Саме завдяки формам ми можемо реєструватися, писати коментарі, робити замовлення в інтернет-магазинах!

Основний тег <form>

<form action="/send-data" method="POST">
  <!-- Поля форми -->
</form>
action
Адреса, куди відправляються дані форми
method
Метод відправки: GET (видно в URL) або POST (приховано)
name
Ім'я форми (для ідентифікації)

Основні типи полів <input>

<input type="text">
Однорядкове текстове поле
<input type="password">
Поле для пароля (символи приховані)
<input type="email">
Поле для email (перевіряє формат)
<input type="number">
Поле для чисел (з кнопками +/-)
<input type="checkbox">
Прапорець (можна вибрати кілька)
<input type="radio">
Перемикач (можна вибрати один з групи)
<input type="date">
Вибір дати
<textarea>
Багаторядкове текстове поле
<select> + <option>
Випадаючий список
<button> або <input type="submit">
Кнопка відправки форми

Важливі атрибути полів

📌 Основні атрибути

<input type="text" name="username">
<input type="text" placeholder="Введіть ім'я">
<input type="text" value="Текст за замовчуванням">
<input type="text" required>
<input type="text" disabled>

📋 Вікторина: Перевір себе

Що потрібно запам'ятати

  • Форми створюються тегом <form> з атрибутами action та method
  • Поля введення створюються тегом <input> з різними значеннями type
  • <label> пов'язує текст з полем для зручності
  • Атрибут name обов'язковий для відправки даних на сервер
  • required робить поле обов'язковим для заповнення

💻 Практикуємося з формами

💪 Практичне завдання: створи форму реєстрації на сайті. Використай різні типи полів та налаштуй їх атрибути.

Мета практичного заняття

  • Створити форму з різними типами полів
  • Налаштувати атрибути полів (placeholder, required, name)
  • Додати кнопку відправки
  • Потренуватися з різними типами input

Покрокова інструкція

1
Створи структуру форми всередині тегу <form>.
2
Додай текстові поля (ім'я, email, пароль) з атрибутами placeholder та required.
3
Додай перемикачі (radio) для вибору статі.
4
Додай прапорці (checkbox) для вибору інтересів.
5
Додай випадаючий список для вибору країни.
6
Додай кнопку відправки <input type="submit">.

    <h1>📝 Реєстрація на сайті</h1>

        <br><br>
        
        <label>📧 Email: </label>
        <input type="email" name="email" placeholder="example@mail.com" required>
        <br><br>
        
        <label>🔒 Пароль: </label>
        <input type="password" name="password" placeholder="Введіть пароль" required>
        <br><br>
        
        <label>🚻 Стать: </label>
        <input type="radio" name="gender" value="male"> Чоловік
        <input type="radio" name="gender" value="female"> Жінка
        <br><br>
        
        <label>🎯 Інтереси: </label>
        <input type="checkbox" name="interests" value="it"> Програмування
        <input type="checkbox" name="interests" value="sport"> Спорт
        <input type="checkbox" name="interests" value="music"> Музика
        <br><br>
        
        <label>🌍 Країна: </label>

            <option value="ukraine">Україна</option>
            <option value="poland">Польща</option>
            <option value="germany">Німеччина</option>
        </select>
        <br><br>
        
        <label>📝 Про себе: </label>
        <textarea name="about" rows="4" cols="40" placeholder="Розкажи трохи про себе..."></textarea>
        <br><br>
        
        <input type="submit" value="Зареєструватися">
    </form>
</body>
</html>
