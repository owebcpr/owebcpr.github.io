🔗 Гіперпосилання: серце Всесвітньої павутини

🎯 Мета заняття: Зрозуміти, чому посилання — найважливіший елемент інтернету, навчитися створювати посилання різних типів, працювати з якорями та атрибутами.

Історія виникнення: як з'явилися гіперпосилання

У 1965 році Тед Нельсон вигадав термін "гіпертекст" — текст, який може вести до іншого тексту. Але саме сер Тім Бернерс-Лі у 1989 році реалізував цю ідею в HTML. Посилання — це те, що зробило інтернет Всесвітньою павутиною! Без посилань веб був би просто набором окремих файлів.

Цікавий факт: Перше у світі гіперпосилання вело з сайту http://info.cern.ch на інформацію про проект WorldWideWeb. Сьогодні в інтернеті трильйони посилань!

Що таке гіперпосилання?

Гіперпосилання (або просто посилання) — це елемент на веб-сторінці, який дозволяє перейти до іншої сторінки, файлу, розділу або зовнішнього сайту.

<a href="https://google.com">Перейти на Google</a>

Тег <a> (від англ. anchor — якір) — головний тег для створення посилань. Атрибут href вказує адресу переходу.

Види посилань

🌍 Зовнішні (глобальні)

Ведуть на інші сайти в інтернеті.

<a href="https://google.com">Google</a>
→ Приклад: Google

📁 Внутрішні (локальні)

Ведуть на інші сторінки вашого сайту.

<a href="about.html">Про нас</a>
→ Приклад: Про нас

⚓ Якоря (внутрішньосторінкові)

Переміщують по сторінці до певного місця.

<a href="#footer">До підвалу</a>
→ Приклад: До підвалу

📎 Посилання на файли

Відкривають або завантажують файли.

<a href="file.pdf">Завантажити PDF</a>
→ Приклад: Завантажити

Важливі атрибути посилань

href
Адреса, куди веде посилання (обов'язковий)
target="_blank"
Відкриває посилання в новій вкладці
target="_self"
Відкриває в поточній вкладці (за замовчуванням)
title
Підказка при наведенні миші
download
Завантажує файл замість відкриття
rel="nofollow"
Вказує пошуковим системам не враховувати посилання

📋 Вікторина: Перевір себе

Що потрібно запам'ятати

  • Посилання створюються тегом <a> з атрибутом href
  • target="_blank" — відкриває посилання в новій вкладці
  • Якорі (#id) дозволяють переміщатися по сторінці
  • Посилання — це те, що робить веб Всесвітньою павутиною
  • Завжди додавайте атрибут title для доступності

💻 Практикуємося з гіперпосиланнями

💪 Практичне завдання: створи власну навігаційну систему, навчися робити зовнішні, внутрішні посилання та якорі.

Мета практичного заняття

  • Створити меню навігації з кількох сторінок
  • Додати зовнішні посилання на улюблені сайти
  • Зробити якоря для швидкої навігації по сторінці
  • Використати атрибут target="_blank"

Покрокова інструкція

1
Створи базову структуру HTML-документа.
2
Додай меню навігації з посиланнями на різні розділи сторінки (якоря).
3
Додай зовнішні посилання на 3-5 улюблених сайтів з атрибутом target="_blank".
4
Створи "Посилання наверх" за допомогою якоря.
5
Додай підказки до посилань через атрибут title.
🎯 Завдання-челендж

Створи сторінку "Моя улюблена подорож", яка має містити:

  • Меню навігації з 3+ якорями (Про подорож, Галерея, Поради)
  • Зовнішнє посилання на сайт з цікавим місцем (target="_blank")
  • Внутрішнє посилання на іншу сторінку (файл tips.html)
  • Посилання на пошту (mailto:example@mail.com)
  • Посилання "Наверх" в кінці сторінки
  • Атрибут title для кожного посилання

✏️ Спробуй сам! Пиши код нижче

index.html
Приклад готової сторінки: 
<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <title>Моя улюблена подорож</title>
</head>
<body>
    <h1 id="top">🌍 Моя улюблена подорож: Японія</h1>
    
    <!-- Меню навігації (якоря) -->
    <ul>
        <li><a href="#about" title="Перейти до опису подорожі">Про подорож</a></li>
        <li><a href="#gallery" title="Перейти до фотогалереї">Галерея</a></li>
        <li><a href="#tips" title="Поради мандрівникам">Поради</a></li>
    </ul>
    
    <!-- Зовнішні посилання -->
    <p>Дізнатися більше: 
        <a href="https://www.japan.travel/uk/" target="_blank" title="Офіційний туристичний сайт Японії">
            Japan Travel
        </a>
    </p>
    
    <!-- Внутрішнє посилання -->
    <p><a href="tips.html" title="Корисні поради">Переглянути поради</a></p>
    
    <!-- Посилання на пошту -->
    <p>📧 Пишіть мені: 
        <a href="mailto:travel@example.com" title="Написати листа">travel@example.com</a>
    </p>
    
    <h2 id="about">🗻 Про подорож</h2>
    <p>Японія - це неймовірна країна...</p>
    
    <h2 id="gallery">📸 Галерея</h2>
    <p>Тут будуть фотографії...</p>
    
    <h2 id="tips">💡 Поради</h2>
    <p>Поради для подорожі...</p>
    
    <!-- Посилання "Наверх" -->
    <p><a href="#top" title="Повернутися наверх">⬆ Наверх</a></p>
</body>
</html>
