📁 Створення HTML-файлів та структура документа

💪 Практикуємося з файлами та папками! Сьогодні ми навчимося правильно створювати HTML-проєкти, організовувати файлову структуру та писати базову розмітку.

📂 Як організувати HTML-проєкт

  1. 📁 Створи окрему папку для проєкту (наприклад, my_site)
  2. 📄 У цій папці створи файл index.html — головну сторінку
  3. 📁 Для зображень створи папку images/ або img/
  4. 📁 Для стилів — css/, для скриптів — js/
  5. 🌐 index.html — це ім'я за замовчуванням, яке сервер показує першим
my_site/
  📄 index.html  <-- головна сторінка
  📂 images/  <-- папка для картинок
     🖼️ cat.jpg
  📂 css/  <-- папка для стилів
     🎨 style.css

Відео: створення файлу та папок у VS Code

🧱 Загальна структура HTML-документа

Обов'язкові частини

Кожен HTML-документ має:

  • <!DOCTYPE html> — оголошення типу документа
  • <html> — кореневий елемент
  • <head> — метадані, заголовок, підключення файлів
  • <body> — видимий контент

Важливі правила

  • Файл має закінчуватися на .html
  • Ім'я головної сторінки — index.html
  • Теги мають бути закриті
  • Правильна вкладеність
<!DOCTYPE html>
<html lang="uk">
  <head>
    <meta charset="UTF-8">
    <title>Моя перша сторінка</title>
  </head>
  <body>
    <h1>Вітаю!</h1>
    <p>Це мій перший HTML-документ</p>
  </body>
</html>
🎯 Завдання-челендж

Завдання: Створи структуру проєкту "Моє хобі" та напиши базовий HTML-файл.

  • 📁 Створити папку my_hobby на комп'ютері
  • 📄 У папці створити файл index.html
  • 📁 Створити папку images всередині проєкту
  • 🧱 Написати базову структуру HTML (!DOCTYPE, html, head, body)
  • ✏️ Додати заголовок сторінки <title> — "Моє хобі"
  • 📝 У тілі <body> написати заголовок <h1> і абзац <p> про хобі
  • 💾 Зберегти файл і відкрити у браузері
