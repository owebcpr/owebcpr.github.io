Як створити HTML-проєкт у Visual Studio Code

  1. 📁 Відкрий Visual Studio Code
  2. 📂 Натисни File → Open Folder і обери папку для проєкту
  3. ➕ У лівій панелі (Explorer) натисни праву кнопку миші → New File
  4. 📄 Назви файл index.html
  5. ✏️ Пиши код у файлі
  6. 🌐 Збережи файл (Ctrl+S) і відкрий його у браузері (подвійний клік)

Подивись відео-інструкцію, щоб краще зрозуміти процес

Нові HTML-теги

<img> — зображення

Вставляє картинку на сторінку. Має обов'язкові атрибути:

src — шлях до файлу
alt — альтернативний текст
Приклад: <img src="photo.jpg" alt="Моє фото">

<a> — посилання

Створює гіперпосилання на іншу сторінку або сайт.

href — адреса переходу
Приклад: <a href="https://google.com">Google</a>
🎯 Завдання-челендж

Створи сторінку "Моя улюблена тварина", яка має містити:

  • Заголовок <h1> з назвою тварини
  • Абзац <p> з описом тварини
  • Зображення <img> тварини (можна використати посилання з інтернету)
  • Маркований список <ul> з цікавими фактами (3 факти)
  • Посилання <a> на вікіпедію або сайт про тварину
