🎬 Аудіо та відео на Web-сторінці

🎯 Мета заняття: Вивчити способи вставки відео та аудіо на веб-сторінку, ознайомитися з тегами <video>, <audio> та <iframe> для вбудовування контенту з YouTube.

Як з'явилося відео в інтернеті

Перше відео в інтернеті було завантажено у 1997 році! А у 2005 році з'явився YouTube, який зробив відео доступним для всіх. Сьогодні відео становить понад 80% всього трафіку в інтернеті!

Цікавий факт: Перший відеоплеєр у браузері з'явився лише у 2009 році з HTML5. До цього для перегляду відео використовували плагін Flash!

Тег <video> — вставка відео

Тег <video> дозволяє вбудувати відеофайл безпосередньо на сторінку зі стандартними елементами керування.

<video controls width="600">
  <source src="video.mp4" type="video/mp4">
  Ваш браузер не підтримує відео
</video>
controls
Показує кнопки відтворення, паузи, гучності
autoplay
Автоматичне відтворення (з обережністю!)
loop
Зациклює відтворення
muted
Вимикає звук за замовчуванням
poster
Зображення-заставка до початку відео
width / height
Розмір відеоплеєра

Тег <audio> — вставка аудіо

<audio controls>
  <source src="music.mp3" type="audio/mpeg">
  Ваш браузер не підтримує аудіо
</audio>

🎵 Підтримувані формати

  • .mp3 — найпоширеніший
  • .ogg — відкритий формат
  • .wav — без стиснення

📌 Важливі атрибути

controls — панель керування
autoplay — авто відтворення
loop — зациклити
muted — без звуку

Вставка відео з YouTube

Найпростіший спосіб додати відео на сайт — вбудувати його з YouTube за допомогою тегу <iframe>.

Як отримати код для вставки:

  1. 📺 Відкрий відео на YouTube
  2. 🔘 Натисни кнопку "Поділитися" під відео
  3. 📋 Обери "Вбудувати" (Embed)
  4. 📄 Скопіюй код <iframe>
  5. ✏️ Встав його на свою сторінку
<iframe width="560" height="315"
  src="https://www.youtube.com/embed/VIDEO_ID"
  frameborder="0" allowfullscreen>
</iframe>

Зверни увагу! Замість VIDEO_ID потрібно вставити унікальний код відео з YouTube (наприклад, dQw4w9WgXcQ).

Жива демонстрація

Ти можеш натиснути "Поділитися" під будь-яким відео на YouTube та отримати такий самий код!

💻 Практикуємося з аудіо та відео

💪 Практичне завдання: навчимося вставляти відео з YouTube, а також власні відео та аудіофайли.

Завдання 1: Встав відео з YouTube

Скопіюй код для вставки з будь-якого відео на YouTube та встав його в редактор нижче.

Інструкція:

  1. 📺 Відкрий YouTube та обери будь-яке відео
  2. 🔘 Натисни "Поділитися" → "Вбудувати"
  3. 📋 Скопіюй код (починається з <iframe>)
  4. ✏️ Встав його в редактор коду нижче

✏️ Спробуй сам! Встав свій код

index.html

Завдання 2: Встав власне відео

Створи код для вставки відео за допомогою тегу <video>. Файл myvideo.mp4 збережи в папку з проєктом.

<video controls width="600">
  <source src="myvideo.mp4" type="video/mp4">
  Ваш браузер не підтримує відео
</video>
Підказка: додай атрибути autoplay muted loop для автоматичного відтворення без звуку.

Завдання 3: Встав аудіо

Створи код для вставки аудіо за допомогою тегу <audio>. Файл myaudio.mp3 збережи в папку з проєктом.

<audio controls>
  <source src="myaudio.mp3" type="audio/mpeg">
  Ваш браузер не підтримує аудіо
</audio>
Підказка: додай атрибут loop для зациклення.

  • Аудіо (файл audio.mp3) з атрибутами controls loop
  • Красиве оформлення (стилі можна взяти з попередніх занять або додати свої)
