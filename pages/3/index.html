🛠️ Програмне забезпечення Web-розробника

💻 Щоб створювати сайти, потрібні правильні інструменти. Розберемо, які програми допомагають розробникам писати код, тестувати сайти та працювати в команді.

Що таке сайти?

Сайт — це набір веб-сторінок, які зберігаються на спеціальних комп'ютерах — веб-серверах. Розробники пишуть код (HTML, CSS, JavaScript), зберігають його у файли, і потім розміщують ці файли на сервері. Коли ми вводимо адресу сайту, браузер звертається до сервера й завантажує сторінки.

Статичні сайти
Прості сторінки з текстом, зображеннями, без складної взаємодії.
Динамічні сайти
Вміст змінюється залежно від дій користувача (соцмережі, магазини).

Необхідне ПЗ для Web-розробника

Браузери

Google Chrome, Firefox, Edge — показують результат коду. Мають інструменти розробника, де можна перевірити код, стилі, помилки.

Локальні сервери

Live Server (розширення VSCode), MAMP, LocalWP — запускають сайт на вашому комп'ютері під час розробки.

Редактори коду

VSCode, Sublime Text, Notepad++ — для написання коду з підсвіткою та автодоповненням.

Системи контролю версій

Git — зберігає історію змін у коді, дозволяє працювати в команді.

Знайомство з редакторами коду

Код для вебсайтів можна писати навіть у Блокноті. Ось приклад простого HTML-файлу:

<!DOCTYPE html>
<html>
  <head>
    <title>Мій перший сайт</title>
  </head>
  <body>
    <h1>Привіт, світ!</h1>
  </body>
</html>

Але працювати з великими проєктами в Блокноті — незручно. Тому розробники використовують спеціальні редактори коду з підсвіткою, автодоповненням, розширеннями та інтеграцією з терміналом.

✅ Sublime Text — легкий і швидкий
⚠️ Atom — зручний, але розвиток припинено у 2022 р.
⚠️ Brackets — застарілий, live preview
✅ Notepad++ — розширений Блокнот

🏆 Найкращий вибір: Visual Studio Code (VSCode)

  • Безкоштовний та з відкритим кодом
  • Працює на Windows, macOS, Linux
  • Вбудований термінал, Git, дебагер
  • Величезна бібліотека плагінів
  • Постійно оновлюється

Завантажити VSCode: code.visualstudio.com

Налаштування середовища програмування

1

Створення файлів і папок у VSCode

File → Open Folder → створи файл (New File) з розширенням .html, .css

2

Встановлення плагінів

Ctrl+Shift+X → пошук → Install. Найпопулярніші: Live Server, Auto Rename Tag, vscode-icons.

3

Emmet та гарячі клавіші

Скорочення на кшталт ul>li*3 → розгортаються у HTML. Ctrl+P, Ctrl+`, Alt+Shift+F — прискорюють роботу.

4

Node.js

Потрібен для сучасних інструментів (SASS, webpack). Завантажте з nodejs.org
