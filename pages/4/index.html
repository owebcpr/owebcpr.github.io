Visual Studio Code (VSCode)

💻 Visual Studio Code (VSCode) — дуже потужний і зручний редактор. Він має багато функцій, які значно полегшують веброзробку. Давайте розглянемо, як з ним працювати.

Як створити файли та папки у VSCode

1

Відкрий VSCode

Запусти редактор.

2

Відкрий папку проєкту

File → Open Folder — обери папку, де зберігатимеш проєкт.

3

Створи файл / папку

У лівій панелі (Explorer) → права кнопка миші → New File або New Folder.

4

Назви файл

Наприклад, index.html, style.css — і файл готовий до редагування.

5

Відкрий файл

Просто клікни по ньому у списку зліва.

Як встановлювати плагіни (розширення)

Крок 1

Натисни Ctrl+Shift+X або натисни на іконку Extensions у лівій панелі.

Крок 2

У полі пошуку введи назву розширення (наприклад: Live Server).

Крок 3

Натисни Install — плагін буде встановлено.

🚀 Робота з командами та скороченнями (Emmet)

VSCode підтримує технологію Emmet — це скорочення, які розгортаються у повноцінний HTML-код. Наприклад:

ul>li*3 → створює список із трьох пунктів

📖 Детальний список команд Emmet: docs.emmet.io/cheat-sheet/

🧠 Інтерактивна вікторина: Впізнай розширення VSCode!

💡 Порада: Налаштуй VSCode під себе!

Заходь у File → Preferences → Settings (або Ctrl+,) і змінюй шрифт, тему, розмір відступів — обери те, що тобі зручно.

Натисни, щоб дізнатися щось нове про VSCode!
