🎨 Робота з кольором у CSS

🎯 Мета заняття: Вивчити способи задання кольорів у CSS: за назвою, HEX, RGB, RGBA. Навчитися використовувати властивості color та background-color.

📖 Цікава історія: Як кольори потрапили в інтернет

1994 рік. Перші веб-сторінки були сірими і нудними. Вони мали лише чорний текст на сірому фоні.

Все змінилося, коли браузери почали підтримувати кольори. Спочатку було лише 16 базових кольорів (як-от red, blue, green).

Чому саме червоний, зелений і синій?

👁️

Біологія ока: Людське око має три типи колбочок — фоторецепторів, чутливих до червоного, зеленого та синього світла. Саме ці три кольори наш мозок використовує для створення всіх інших кольорів, які ми бачимо.

🖥️

Технологія моніторів: Кожен піксель на екрані монітора складається з трьох субпікселів — червоного, зеленого та синього. Змінюючи яскравість кожного з них, монітор може відтворити понад 16 мільйонів різних кольорів!

🎨

Модель RGB: Це адитивна модель кольору — чим більше світла, тим світліший колір. Коли всі три канали (R, G, B) мають значення 255, ми бачимо білий колір. Коли всі 0 — чорний.

🌈

Цікавий факт: Ваш монітор, смартфон або телевізор використовують RGB-модель для відображення всіх кольорів. Саме тому CSS використовує rgb(255, 0, 0) — це команда для монітора: «зроби червоний субпіксель максимально яскравим, а зелений і синій — вимкни».

Сьогодні CSS підтримує понад 16 мільйонів кольорів! Це стало можливим завдяки HEX-кодам та RGB-моделі. Кожен колір можна описати точними значеннями.

🎨 Цікавий факт: Назва 'rebeccapurple' була додана до CSS на честь Ребекки Меєр, доньки відомого веб-розробника Еріка Меєра.

Способи задання кольорів у CSS

У CSS існує 4 основні способи задання кольорів. Кожен з них має свої переваги та використовується в різних ситуаціях.

🔤 1. Кольори за назвою (Color Names)

Найпростіший спосіб — використовувати англійські назви кольорів. У CSS доступно 140 стандартних назв.

p {
  color: red; /* червоний */
  background-color: lightblue; /* світло-синій фон */
}
red
blue
green
yellow
purple
orange
pink
teal

📌 Повний список кольорів за назвою можна знайти за посиланням: w3schools.com/colors/colors_names

🔢 2. Шістнадцятковий код (HEX)

HEX-код починається з решітки (#) і містить 6 символів (0-9, A-F). Кожна пара символів відповідає за червоний, зелений та синій канали.

p {
  color: #ff0000; /* червоний */
  background-color: #00ff00; /* зелений фон */
}
#FF 00 00 = червоний
00 FF 00 = зелений
00 00 FF = синій
FF FF FF = білий
00 00 00 = чорний

💡 Скорочений запис: якщо символи повторюються, можна писати 3 символи. Наприклад: #f00 = #ff0000, #0f0 = #00ff00

🌈 3. RGB (Red, Green, Blue)

RGB задає колір через три числа від 0 до 255, які відповідають за інтенсивність червоного, зеленого та синього.

p {
  color: rgb(255, 0, 0); /* червоний */
  background-color: rgb(0, 255, 0); /* зелений фон */
}
rgb(255, 0, 0) → червоний
rgb(0, 255, 0) → зелений
rgb(0, 0, 255) → синій
rgb(0, 0, 0) → чорний
rgb(255, 255, 255) → білий

💡 Порада: rgb(255, 255, 255) — це білий, а rgb(0, 0, 0) — чорний. Змінюючи числа, можна отримати будь-який колір!

👻 4. RGBA (з прозорістю)

RGBA — це той самий RGB, але з додатковим параметром прозорості (Alpha) від 0 (повністю прозорий) до 1 (повністю непрозорий).

p {
  color: rgba(255, 0, 0, 0.5); /* червоний з 50% прозорістю */
  background-color: rgba(0, 0, 255, 0.3); /* синій фон з 30% прозорістю */
}
rgba(255, 0, 0, 1) — 100%
rgba(255, 0, 0, 0.7) — 70%
rgba(255, 0, 0, 0.4) — 40%
rgba(255, 0, 0, 0.1) — 10%

Важливо! Прозорість впливає на те, що знаходиться під елементом. Якщо фон прозорий, крізь нього буде видно те, що знаходиться ззаду.

Властивості color та background-color

color
Це колір тексту
h1 {
  color: #e74c3c;
}
background-color
Це колір фону
div {
  background-color: #3498db;
}

Запам'ятай!

  • color — відповідає за колір тексту
  • background-color — відповідає за колір фону елемента
  • Ці властивості можна використовувати разом або окремо
