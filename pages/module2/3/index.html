🎯 Селектори CSS

🎯 Мета заняття: Вивчити різні типи селекторів, їх пріоритети та правила написання. Навчитися правильно обирати селектори для стилізації.

Що таке селектори?

Селектор — це частина CSS-правила, яка визначає, до яких елементів HTML буде застосовано стиль. Він "вибирає" елементи на сторінці.

/* Структура: селектор { властивість: значення; } */
p {
  color: blue;
}

/* p — селектор, вибирає всі елементи <p> на сторінці */

Цікавий факт: У CSS існує понад 50 різних типів селекторів! Але для початку достатньо знати близько 10 основних.

Класифікація селекторів

1️⃣ Прості селектори

Тип Синтаксис Приклад
За тегом тег p { color: red; }
За класом .клас .header { font-size: 24px; }
За ID #ідент #logo { width: 100px; }
Універсальний * * { margin: 0; }

2️⃣ Складені селектори

Тип Синтаксис Приклад
Групування селектор1, селектор2 h1, h2 { color: blue; }
Вкладеність предок нащадок div p { font-weight: bold; }
Дочірній батько > дитина ul > li { list-style: none; }
Сусідній елемент1 + елемент2 h1 + p { margin-top: 0; }
За атрибутом [атрибут] input[type="text"] { width: 100%; }

Пріоритети селекторів

CSS використовує систему специфічності для визначення, який стиль застосувати, якщо є конфлікт.

Пріоритет (від найвищого)

  1. Inline-стилі (style="...")
  2. ID (#id)
  3. Класи, атрибути, псевдокласи (.class, [attr], :hover)
  4. Теги та псевдоелементи (p, ::before)
  5. Універсальний селектор (*)

Приклад

/* Найвищий пріоритет */
#main { color: red; }
.text { color: blue; }
p { color: green; }

/* Застосується red (ID має вищий пріоритет) */

Заголовок h2

Цей абзац має стати жирним (він йде одразу після h2).

А цей абзац не зміниться (він не йде одразу після h2).

h2 + p {
  font-weight: bold; // Додай цей рядок
}
