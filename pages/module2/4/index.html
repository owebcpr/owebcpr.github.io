📝 Стилі для тексту

🎯 Мета заняття: Вивчити основні CSS-властивості для стилізації тексту: колір, розмір, жирність, нахил, вирівнювання, трансформацію, інтервали та оформлення.

📖 Цікава історія: Як текст став стильним

1989 рік, Європа. Молодий учений Тім Бернерс-Лі працював над створенням Всесвітньої павутини (World Wide Web). Він хотів, щоб люди могли обмінюватися документами через інтернет.

Але була проблема — усі сторінки виглядали однаково: сірий текст на сірому тлі. Не було ні кольорів, ні жирного шрифту, ні курсиву. Це було нудно і невиразно.

1996 рік — з'явився CSS (Cascading Style Sheets). Тепер веб-сторінки могли бути яскравими, жирними, елегантними та оформленими.

Сьогодні CSS — це мова стилів, яка робить інтернет красивим та різноманітним. Кожна сторінка, яку ти бачиш, використовує CSS-властивості для тексту!

📌 Цікавий факт: Перший браузер, який підтримав CSS, вийшов у 1996 році — це був Internet Explorer 3.0.

Основні властивості тексту

CSS надає багато властивостей для керування зовнішнім виглядом тексту. Розглянемо найважливіші з них.
