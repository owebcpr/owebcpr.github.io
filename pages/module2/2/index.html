🎯 Мета заняття: Вивчити структуру CSS-правила, основні селектори, властивості та значення. Навчитися писати правильний CSS-код.

Структура CSS-правила

CSS-правило складається з селектора, фігурних дужок {}, всередині яких знаходяться оголошення (властивість: значення;). Кожне оголошення закінчується крапкою з комою ;

селектор {
  властивість: значення;
}
/* Приклад */
h1 {
  color: blue;
  font-size: 24px;
}

Запам'ятай! Кожне оголошення має бути написане саме так: властивість: значення;. Крапка з комою в кінці обов'язкова!

Завдання 1 ⏳ Очікує
🎯 Завдання: Додай стиль для тегу p: color: blue;

Цей текст має стати синім.

p {
  color: blue; // Додай цей рядок
}
Завдання 2 ⏳ Очікує
🎯 Завдання: Додай стиль для класу .highlight: background: yellow;

Цей текст має отримати жовтий фон.

.highlight {
  background: yellow; // Додай цей рядок
}
Завдання 3 ⏳ Очікує
🎯 Завдання: Додай стиль для ID #main: font-size: 24px;

Цей текст має стати більшим (24px).

#main {
  font-size: 24px; // Додай цей рядок
}
Завдання 4 ⏳ Очікує
🎯 Завдання: Додай два стилі для h2: color: green; та text-decoration: underline;

Цей заголовок має стати зеленим і підкресленим.

h2 {
  color: green; // Додай цей рядок
  text-decoration: underline; // І цей
}
Завдання 5 ⏳ Очікує
🎯 Завдання: Додай стиль для div p: font-weight: bold;

Цей текст у div має стати жирним.

div p {
  font-weight: bold; // Додай цей рядок
}
Завдання 6 ⏳ Очікує
🎯 Завдання: Додай стиль для h3, h4: color: purple;

Цей заголовок h3 має стати фіолетовим.

І цей h4 теж має стати фіолетовим.

h3, h4 {
  color: purple; // Додай цей рядок
}
