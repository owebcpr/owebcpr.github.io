🎨 Що таке CSS. Способи підключення

🎯 Мета заняття: Зрозуміти, що таке CSS, дізнатися історію виникнення стилів, вивчити три способи підключення та основні селектори.

Історія виникнення CSS

До появи CSS веб-сторінки виглядали дуже просто і однотипно. Дизайн робили за допомогою тегів <font>, <b> та атрибутів color, bgcolor. Це було незручно, бо код ставав величезним і важким для підтримки.

Цікавий факт: CSS (Cascading Style Sheets) був створений у 1996 році норвезьким програмістом Хоконом Віум Лі. Він хотів, щоб веб-сторінки мали не лише структуру, а й гарний зовнішній вигляд. Перший браузер, який підтримав CSS — Internet Explorer 3.0 у 1997 році.

Важливо! Сьогодні CSS — це мова, яка постійно розвивається. CSS3 додав анімації, Flexbox, Grid та багато інших сучасних можливостей.

Три способи підключення CSS

1️⃣ Inline-стилі (вбудовані)

Додаються безпосередньо в HTML-тег через атрибут style.

<!-- Inline-стиль -->
<h1 style="color: red; font-size: 32px;">Привіт, світ!</h1>

Мінуси: Погано підтримується, важко змінювати, порушує принцип розділення змісту і вигляду. Сьогодні майже не використовується.

2️⃣ Внутрішні стилі (internal)

Пишуться в блоці <style> у розділі <head>.

<!-- Внутрішній стиль -->
<style>
  h1 {
    color: red;
    font-size: 32px;
  }
</style>

Мінуси: Підходить лише для однієї сторінки. Якщо сторінок багато — доведеться копіювати код в кожну.

3️⃣ Зовнішній файл (external) — найкращий спосіб!

Створюється окремий файл з розширенням .css, який підключається через тег <link>.

<!-- Спочатку створюємо файл style.css -->
/* style.css */
h1 {
  color: red;
  font-size: 32px;
}

<!-- Потім підключаємо в HTML -->
<link rel="stylesheet" href="style.css">

Переваги: Код перевикористовується на багатьох сторінках, легше підтримувати, кешується браузером (швидше завантаження), краще для SEO.

📋 Вікторина: перевір себе

Що запам'ятати

  • CSS — каскадні таблиці стилів, відповідають за вигляд сторінки.
  • 3 способи підключення: inline, internal, external.
  • Зовнішній CSS (external) — найкращий для великих проєктів.
  • Основні селектори: тег, .class, #id, *.
  • CSS називається "каскадним", бо враховує порядок та пріоритет правил.

💻 Практикуємо CSS: стилізуємо сторінку

💪 Практичне завдання: створи та стилізуй сторінку про улюблену тварину, використовуючи різні способи підключення CSS.

Мета практичного заняття

  • Навчитися підключати CSS трьома способами.
  • Використовувати селектори, кольори, шрифти.
  • Створити власний дизайн для сторінки "Моя улюблена тварина".

Покрокова інструкція

1
Створи базову HTML-структуру з заголовками, абзацами, списком.
2
Додай внутрішній CSS у <head> для основних кольорів та шрифтів.
3
Створи зовнішній файл style.css (можна імітувати в редакторі) для складніших стилів.
4
Використай inline-стилі для одного елемента (наприклад, колір заголовка).

  • Inline-стиль (наприклад, колір заголовка)

index.html + style.css (вбудований)
Підказка: Використовуй тег <style> у <head> для внутрішнього CSS, або атрибут style для inline. 
<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <title>Панда</title>
    <style>
        body { background: #f0f8ff; font-family: 'Segoe UI', sans-serif; }
        .card { background: white; border-radius: 20px; padding: 20px; box-shadow: 0 8px 20px rgba(0,0,0,0.1); margin: 20px; }
        h1 { color: #2c3e50; }
        .highlight { background: #ffd966; padding: 0 5px; }
    </style>
</head>
<body>
    <div class="card">
        <h1 style="color:#1e5f7a;">🐼 Панда</h1>
        <h2>Опис</h2>
        <p>Панда — <strong>рідкісна</strong> тварина, що живе в Китаї. <em>Чорно-біле забарвлення</em> робить її впізнаваною.</p>
        <h2>Факти</h2>
        <ul>
            <li>Їсть <span class="highlight">14 годин</span> на день</li>
            <li>Має <strong>6 пальців</strong> на лапах</li>
        </ul>
    </div>
</body>
</html>
