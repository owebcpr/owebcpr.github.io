🔤 Web-шрифти

🎯 Мета заняття: Вивчити, що таке веб-шрифти, як їх підключати до сторінки та використовувати різні способи підключення.

📖 Цікава історія: Як з'явилися веб-шрифти

1990-ті роки. Веб-сторінки використовували лише шрифти, встановлені на комп'ютері користувача. Якщо шрифту не було — браузер показував стандартний.

У 1996 році CSS представив властивість font-family, але дизайнери все одно залежали від того, які шрифти встановлені на комп'ютері користувача.

Справжній прорив стався у 2009 році, коли з'явився @font-face — CSS-правило, яке дозволяло завантажувати шрифти з сервера. Тепер будь-який шрифт міг бути використаний на будь-якій сторінці!

Сьогодні існують тисячі безкоштовних шрифтів на Google Fonts та інших платформах. Веб-шрифти зробили інтернет елегантним, яскравим та різноманітним.

📌 Цікавий факт: Назва 'Georgia' була створена спеціально для екранів моніторів у 1996 році.

Що таке веб-шрифти?

Веб-шрифт — це шрифт, який завантажується з інтернету і відображається на сторінці незалежно від того, чи є цей шрифт на комп'ютері користувача. Це дозволяє використовувати будь-які шрифти на вашому сайті.

📂 Формати шрифтів

Формат Розширення Підтримка браузерами
TTF .ttf Всі сучасні браузери
OTF .otf Всі сучасні браузери
WOFF .woff Всі сучасні браузери (стиснутий)
WOFF2 .woff2 Всі сучасні браузери (краще стиснутий)
EOT .eot Тільки Internet Explorer (застарілий)
SVG .svg Застарілий, не використовується

💡 Сучасні браузери: WOFF та WOFF2 — це найкращий вибір, оскільки вони стиснуті і швидко завантажуються.

🏷️ Сімейства шрифтів (font-family)

p {
  font-family: "Arial", "Helvetica", sans-serif;
  /* Браузер шукає Arial, якщо ні — Helvetica, якщо ні — будь-який sans-serif */
}

Важливо: Якщо назва шрифту складається з кількох слів — беріть її в лапки. Наприклад: "Times New Roman"

Способи підключення веб-шрифтів

🔤 1. Стандартні шрифти браузера

Це шрифти, які вже встановлені на комп'ютері користувача. Вони не потребують завантаження і працюють одразу.

/* Найпоширеніші стандартні шрифти */
.serif-text { font-family: Georgia, "Times New Roman", serif; }
.sans-text { font-family: Arial, "Helvetica", sans-serif; }
.mono-text { font-family: "Courier New", monospace; }
Serif Це шрифт із засічками
Sans-serif Це шрифт без засічок
Monospace Це моноширинний шрифт

Плюси: Не потребують завантаження, працюють миттєво.

Мінуси: Обмежений вибір, вигляд залежить від комп'ютера користувача.

📦 2. Підключення через @font-face

Це CSS-правило, яке дозволяє завантажити шрифт з вашого сервера або з зовнішнього джерела.

@font-face {
  font-family: "MyFont";
  src: url("fonts/MyFont.woff2") format("woff2"),
     url("fonts/MyFont.woff") format("woff");
  font-weight: normal;
  font-style: normal;
}

p { font-family: "MyFont", sans-serif; }
1
Завантаж шрифт у форматі WOFF2 (або WOFF).
2
Помісти файл у папку fonts/ на сервері.
3
Додай @font-face у CSS.
4
Використовуй шрифт через font-family.

Плюси: Повний контроль над шрифтами, працює без інтернету (після завантаження).

Мінуси: Потрібен хостинг для файлів, можуть бути проблеми з ліцензіями.

🌐 3. Підключення через Google Fonts

Google Fonts — це безкоштовна бібліотека з понад 1500 шрифтів. Підключення займає 2 хвилини!

Спосіб А: Через HTML-посилання (у <head>)
<!-- У <head> додай це посилання -->
<link href="https://fonts.googleapis.com/css2?family=Roboto:wght@400;700&display=swap" rel="stylesheet">
Спосіб Б: Через @import у CSS
/* На початку CSS-файлу */
@import url('https://fonts.googleapis.com/css2?family=Roboto:wght@400;700&display=swap');

p { font-family: 'Roboto', sans-serif; }
1
Зайди на fonts.google.com
2
Обери шрифт (наприклад, Roboto)
3
Натисни Select та обери потрібні стилі (жирність)
4
Скопіюй посилання або код імпорту
5
Додай у свій HTML або CSS
Google Fonts Roboto — це сучасний шрифт

Плюси: Безкоштовно, величезний вибір, швидке завантаження.

Мінуси: Потрібен інтернет для завантаження, можливі невеликі затримки.
